# 📋 TaskListBot

**TaskListBot** — это ваш персональный ассистент в Telegram для управления задачами, напоминаниями и днями рождения. Бот помогает структурировать вашу жизнь, не выходя из мессенджера.

---

[Ссылка на бота в Telegram](https://t.me/MainTaskListBot)

---

## 🚀 Основные команды

| Команда              | Описание |
|----------------------|----------|
| `/start`             | Регистрация в системе |
| `/help`              | Показать список всех доступных команд |
| `/user`              | Показать информацию о вашем профиле |

---

## 📌 Команды списка задач

| Команда (сокращение) | Описание |
|----------------------|----------|
| `/task_list` (`/tl`) | Отобразить список задач |
| `/add_task` (`/at`)  | Добавить задачу |
| `/edit_task` (`/et`) | Изменить задачу |
| `/delete_task` (`/dt`)| Удалить задачу |
| `/clear_task_list` (`/ctl`)| Очистить список задач |

---

| Команда (сокращение) | Описание                               |

| `/reminder_list` (`/rl`) | Отобразить список напоминаний у задачи |

| `/clear_reminder_list` (`/crl`)| Очистить список напоминаний у задачи   |
